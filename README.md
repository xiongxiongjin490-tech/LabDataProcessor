# 理工科实验数据处理器

纯前端单文件工具（深色科技风）：录入实验原始读数，自动完成不确定度评定、描述统计、异常值判别、线性 / 非线性拟合、逐差法、误差传递、修约与 t 因子、电路参数、RC 时间常数、光学干涉计算、数电真值表核对与卡诺图化简，并附基础计算器、函数作图采样表、单位换算与实验报告生成工具。导航按 **通用工具 / 测量与不确定度 / 电路实验 / 数电实验 / 专项实验** 分组，常用工具排在最前；通用工具不挂在电路、数电条目下。每个面板均在左侧列出所用公式与判定规则，便于核对计算过程。全部计算在浏览器本地完成，不上传任何数据。

## 功能模块

### 一、通用工具（最常用）

#### 基础计算器
通用表达式计算，不依赖外部库，解析在本地完成。

- 四则、括号、幂 `^`、开方 `sqrt`、阶乘 `!`，支持隐式乘法（`2π`、`2(3+4)`）
- 函数：`sin cos tan asin acos atan ln log10 exp abs`；常数 `π`、`e`
- 角度 / 弧度切换；保留最近 20 条记录，点击回填
- 表达式解析器为递归下降实现，不使用 `eval`，非法输入给出明确错误提示

#### 单位换算
覆盖九类常用量，双向换算并显示换算公式。

- 长度、质量、时间、压力 / 压强、面积、体积、速度、数据存储
- 一般物理量：`目标值 = 输入值 × k_from / k_to`
- 温度非线性换算：`°F = °C×9/5+32`，`K = °C+273.15`
- 数据存储按 1024 进制；支持一键交换起止单位

#### 函数作图 · 采样表
输入一元函数 `y = f(x)` 与区间，自动等间隔采样、作图并生成数据表。

- 采样：`x_i = x_min + i·(x_max−x_min)/(N−1)`，`y_i = f(x_i)`
- 内置 SVG 函数曲线（含坐标轴、网格、采样点），可保存 SVG
- 统计最小 / 最大值、首末点；数据表可复制 TSV 或导出 CSV
- 区间内无定义的点记为空，不参与最值统计

#### 实验报告生成
汇总你在各模块中已经计算出的结果表与图表，生成可打印的实验报告。

- 自动收集各模块的结果表、明细表与拟合 / 函数曲线图，未计算的模块不纳入
- 可填写实验名称与日期；一键打印或另存为 PDF（打印样式已分离导航与操作按钮）

### 二、测量与不确定度（物理 / 电路实验通用）

#### 重复测量 · 不确定度评定
适用于物理、电路实验中对同一量进行多次重复测量的场合（如电阻、电压、长度等）。

- 算术平均值 `x̄`、实验标准差 `s`（贝塞尔公式）
- A 类标准不确定度 `u_A = s/√n`
- B 类标准不确定度 `u_B = Δ/c`（均匀分布 `c=√3`，可选正态 `c=3`、三角 `c=√6`）
- 合成标准不确定度 `u_c = √(u_A² + u_B²)`
- 扩展不确定度 `U = k·u_c`（包含因子 k 默认为 2）
- 相对不确定度 `E_r = U/|x̄|×100%`
- 填入标准值 x₀ 时，同时给出绝对误差与相对误差
- 自动生成含残差 `vᵢ`、残差平方 `vᵢ²` 的明细表，并按修约规则给出测量结果表示

#### 误差传递 · 间接测量
由直接测量量的最佳值与标准不确定度，合成间接测量量的结果。

- 内置常用模型：和差 `N=A±B`、积 `N=AB`、商 `N=A/B`、幂次 `N=Aᵖ`、密度 `ρ=m/V`、单摆 `g=4π²L/T²`
- 和差按绝对不确定度方和根合成；积、商、幂先按相对不确定度合成再折算绝对不确定度
- 输出间接量最佳值、合成不确定度、相对不确定度与结果表示

#### 描述统计
对一组重复观测值给出完整的汇总统计量。

- 平均值、中位数、最小值 / 最大值、极差
- 样本方差 / 标准差（除以 `n−1`）与总体方差 / 标准差（除以 `n`）
- 四分位 `Q1 / Q3` 与四分位距 `IQR`
- 95% 置信区间 `x̄ ± t_{0.95}(n−1)·s/√n`；附排序值与偏差明细表

#### 修约 · t 因子
按不确定度修约规则整理最佳值与扩展不确定度。

- 自由度 `ν = n−1`，按 t 分布表查包含因子 t（68% 取 k=1；95%、99% 查表，`ν≥30` 近似正态 1.96 / 2.58）
- 扩展不确定度 `U = t·u_c`；U 取 1~2 位有效数字，最佳值末位与 U 末位对齐
- 输出标准结果表示 `x = (x̄ ± U) 单位（置信概率，k=t）`

#### 异常值判别
对样本中的可疑粗大误差给出判别建议（不替代复核记录）。

- 3σ 准则：`|xᵢ − x̄| > 3s` 判为可疑值
- Grubbs 检验（α=0.05）：`G = max|xᵢ − x̄|/s`，比对临界值表 `G_crit(n, 0.05)`
- Dixon Q 检验（n=3~10）：`Q = 相邻差 / 极差`，比对 `Q_crit(n, 0.05)`
- 可疑值标红提示；剔除后应重新计算，不可连续剔除

#### 一元线性拟合
适用于伏安特性曲线、校准曲线、RC 充放电特性等配对 (x, y) 数据。

- 最小二乘拟合 `y = a + bx`，给出斜率、截距及其标准偏差
- 相关系数 `r`、决定系数 `R²`、残差标准差 `s_{y/x}`
- 内置 SVG 散点图与拟合直线，可保存为 SVG 文件
- 明细表列出每个点的拟合值 `ŷ` 与残差

#### 非线性拟合
对常用非线性模型先做变量线性化，再按最小二乘拟合。

- 指数型 `y = a·e^(b·x)`：变换 `Y = ln y`
- 幂函数 `y = a·x^b`：变换 `X = ln x，Y = ln y`
- 对数型 `y = a + b·ln x`：变换 `X = ln x`
- 输出变换后相关系数 r、R²、各点拟合值与残差；内置 SVG 散点与拟合曲线，可保存 SVG / PNG

#### 逐差法
适用于等间隔线性测量：拉伸法测杨氏模量、牛顿环环差、电位差计校准等。

- 2n 个读数前后两半对应相减，求平均逐差 `Δ̄`
- 逐差标准差 `s_Δ`、A/B 类不确定度与合成不确定度
- 折算每单位自变量间隔的变化量 `k = Δ̄/(n·Δx)` 及其不确定度
- 明细表列出每组 `aᵢ、bᵢ、Δᵢ、Δᵢ−Δ̄、偏差²`

### 三、电路实验

#### 电路参数 · 三表法 / 功率因数
适用于三表法测交流阻抗、日光灯电路与功率因数提高等实验。

- 视在功率 `S = UI`，功率因数 `cosφ = P/S`
- 无功功率 `Q = √(S² − P²)`，阻抗 `|Z| = U/I`，电阻 `R = P/I²`，电抗 `X = √(|Z|² − R²)`
- 感性负载换算电感 `L = X/ω`，容性负载换算电容 `C = 1/(ωX)`，`ω = 2πf`
- 按目标功率因数估算所需并联补偿电容 `C = P/(ωU²)(tanφ₁ − tanφ₂)`

#### RC 一阶电路时间常数
适用于零状态 / 零输入响应、RC 充放电波形观测实验。

- 理论计算 `τ = RC`，10%→90% 上升时间 `t_r ≈ 2.2τ`，约 `5τ` 完成 99.3% 充放电
- 波形读数反推：充电到 63.2% U_s、放电到 36.8% U_s 对应的时间，或由 10%→90% 过渡时间 `τ = t_r/2.2`
- 实测 τ 与理论 τ 对比，给出相对误差

### 四、数电实验

#### 数电真值表核对
适用于译码器（74LS138）、数据选择器（74LS153）、加法器（74LS283、BCD 加法）等芯片功能验证。

- 自定义输入位、输出位数量与名称
- 逐行比对实测输出与预期输出，标出不一致的输出位
- 统计已核对行数、待实测行数、一致率；实测留空记为"待实测"，不计为错误

#### 数电工具
进制转换、逻辑表达式真值表、卡诺图化简与常用编码 / 译码表。

- 进制互转：二 / 八 / 十 / 十六进制双向换算
- 表达式 → 真值表：支持 `!` 非、`&` 与、`|` 或、`^` 异或、括号，变量 A~D 全枚举
- 卡诺图化简：奎因-麦克拉斯基算法求最简与或式（SOP），支持 2~4 变量
- 预设表：BCD 8421 码、3-8 译码器（低有效）、4-2 编码器（高有效）

### 五、专项实验

#### 光学干涉计算
覆盖空气劈尖、增透膜、牛顿环三类常见光学实验。

- 空气劈尖：`D = λL/(2l)`（细丝 / 薄片直径）
- 增透膜：最小厚度 `e_min = λ/(4n₂)`，通解 `e = (2k+1)λ/(4n₂)`
- 牛顿环：`R = (d²_{k+m} − d_k²)·n/(4mλ)`，支持充液介质折射率修正

## 使用方法

1. 直接用浏览器打开 `index.html`，无需安装任何依赖、无需联网。
2. 顶部按类别切换模块；部分模块可点"填入示例"查看效果，再替换成自己的读数；多行数据可点"粘贴批量"，从 Excel 直接复制（支持换行、Tab、逗号、空格分隔）。
3. 每个面板左侧"所用公式 / 规则"区集中列出该模块的计算公式与口径，可对照核对过程。
4. 结果区支持：
   - **复制结果表**：复制为 TSV，可直接粘贴进 Excel / Word 报告
   - **导出 CSV**：带 UTF-8 BOM，Excel 直接打开不乱码（CRLF 换行）
   - **保存 SVG 图 / PNG**：线性拟合、非线性拟合、函数作图模块可导出曲线图

## 计算口径说明

- 标准差采用贝塞尔公式（除以 `n−1`）；A 类不确定度为平均值的实验标准差 `s/√n`。
- B 类评定按仪器误差限折算，默认均匀分布 `u_B = Δ_ins/√3`；分布类型可在界面切换。
- 扩展不确定度默认 `k=2`（约 95% 置信概率），可自行修改。
- 线性拟合残差标准差自由度取 `n−2`；斜率、截距标准偏差按最小二乘公式估算。
- 误差传递按各独立直接量偏导（和差）或对数微分（积商幂）的方和根合成。
- t 分布包含因子按自由度 `ν=n−1` 查表；`ν≥30` 近似正态分布。
- 异常值判别仅给出统计建议，是否剔除需结合测量记录与实验规则判断。
- 非线性拟合在变量变换后的坐标下做最小二乘，R² 为变换后坐标的决定系数；残差按原始 y 计算。
- 本工具按大学物理 / 电路实验常用教学口径计算，不替代正式不确定度评定规范。

## 技术说明

- 单个 `index.html`，原生 HTML / CSS / JavaScript，无框架、无第三方库、无外部 CDN。
- 深色科技风界面，图表为手写 SVG；表达式解析为递归下降实现，未使用 `eval`。
- 所有数据仅在当前浏览器内处理，刷新后不保留。推荐最新版 Chrome / Edge / Firefox / Safari。

## 部署到 GitHub Pages

1. 新建仓库（public），上传 `index.html` 与本 README。
2. 仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，分支 `main`，目录 `/(root)`。
3. 保存后通过 `https://<用户名>.github.io/<仓库名>/` 访问。
